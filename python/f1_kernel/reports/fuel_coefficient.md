# Fuel coefficient calibration report

Generated by `python/f1_kernel/tools/calibrate_fuel.py` over 780 stint(s) across 23 session(s) (seasons requested: 2024; min stint laps: 5).

See `f1_kernel.fuel.FuelStintEstimate`'s docstring for why this is a cross-circuit regression of each stint's raw pace slope against that race's fuel burn rate, not a within-stint regression against estimated fuel load (the two are collinear there).

## Result

- `fuel_coef_s_per_kg` = **0.0456**
- 95% CI: [0.0309, 0.0599]
- compounds used: hard, medium

## Method

cross-circuit regression: per-(driver,stint) Theil-Sen slope of clean green-flag lap_time_s vs race lap number, on low-degradation compounds (hard/medium), regressed (Theil-Sen, negated) against that race's fuel burn rate (start_fuel_kg / total_laps); 95% CI is Theil-Sen's own confidence interval on that regression's slope.
